# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (desktop web app at taskora.rabbyhossain.com; the same Flutter code ships the Android app)

## Users
A freelance designer (the owner, Rabby) running client and personal projects, tracking to-dos, notes and earnings. Uses the phone during the day and the web app on a laptop/desktop for longer planning and writing sessions.

## Product Purpose
TaskOra keeps projects, to-dos (with sub-tasks) and notes linked in one place, synced between phone and web through the owner's own server. Success: open it and see what is due, what is moving, and get back to writing or focusing in one click.

## Positioning
Projects, to-dos and notes are connected (to-dos belong to projects, notes live in folders, focus sessions link to to-dos), with freelancer money tracking (platform fees like Fiverr/Upwork) built in.

## Constraints
- Same data and features as the phone app; the web adds a desktop layout only.
- Visual direction for the web redesign (chosen by the owner): "Soft & colorful": keep the pastel cards and purple identity of the phone app, but denser, with no large empty areas.
- Font: Archivo. Accent: the user's chosen theme colour (default indigo #5B5FEF).
