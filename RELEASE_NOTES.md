## New
- Archive and Trash (Profile › Storage): archive or delete projects, to-dos and notes, then restore them. Trash empties itself after 30 days. Select all to restore or delete many at once
- Focus page redesigned. The timer keeps running when you leave, with a live countdown and Pause / +5 min / Stop in your notification panel
- Notification settings: turn notifications on or off, choose which ones, and send a test notification
- Import Word, Google Docs (.docx / .odt) and text files as notes (Notes › upload icon)
- Stats: pick any From – To date range; colours now match your theme
- Projects show as square cards, so cover photos are easy to see (tap the view button for list or board)
- 14 bright new theme colours
- Deadlines can have a time as well as a date

## Better
- Notes: Heading, Subheading, Normal and Small apply to the line you're on, not the whole note
- Notes: flat bullet points you can select and copy in one go
- Notes: tap anywhere to start typing; tap outside to hide the keyboard
- Notes save as you type, so closing the app never loses your writing
- Notes show when they were created and last edited; Home shows note folders as a grid with edit times
- List / grid view now works for folders too
- Projects and to-dos save automatically when you go back (Save changes still works)
- Navigation bar is white, with the selected tab in your theme colour

## Fixed
- Reminders and other notifications now reach your phone's notification panel
